# 同模型自动接力与活动洞察

## 同款模型换供给 不换客户端模型

在模型路由页打开「同模型自动接力」。客户端继续使用原路由 ID，例如 `wb-ACCOUNT/deepseek-v4.1-flash`；网关从**已启用、已导入、同版本同款**的目标中选择供给。DeepSeek Pro、Flash 和其他版本不互相混用。目录里没有的模型不补造，已停用路由不会复活。

接力分为 WB 与其他供应两个隔离分区：`modelRelay.partitions.workbuddy` / `other` 分别控制。WB 模型只接 WB 账号，其他供应之间同型号接力并排除 WB；手工混合配置同样经过分区筛选。停用与已封禁账号退出候选，账号卡与历史仍保留。

默认预留 100 积分及已知额度的 10%。百分比只在有官方总额/响应头上限时计算；未知额度不当成零，人民币余额不与积分比较。新鲜余额最多使用 60 秒。低额时优先另一个同款供给；认证拒绝、额度耗尽、限流、目录缺失、空回答或断流可转下一个。成功供给保持偏好至下次不可用或额度低。

请求中的消息历史、工具定义、工具回执和模型 ID 保持原样，不静默删上下文或降低输出预算。模型目录按主供应可核验能力广播，备用供应逐项按实际输入、工具/图片与输出预算筛选，不因备用窗口较小而压低主供应声明。供给都不可用时返回真实错误，不偷换另一款模型；能力错误不当作真实积分耗尽。

### 流式交接

接力模式对一次完整模型响应先做有界缓冲（32 MiB），确认完成后再发送原流式块。这样即使供给在半途断开，也没有部分正文或拟议工具调用先送给客户端；原请求可由同款供给重新生成，不重复输出、不重复执行工具。代价是首批可见输出在该次模型生成完成后出现。客户端超时和取消优先，已经交付后不重放。

供给默认 30 秒**无有效进展**才超时，正文、推理和工具增量都会刷新进度计时；不是要求整段回答在 30 秒内结束。网关 HTTP 整轮截止与调用端预算仍独立生效；可见首包等待较长可能来自完整响应缓冲，应结合活动记录判断上游是否持续有进展。

四阶段模型体检使用 `source=audit`，完全绕开跨平台接力，避免把替代平台通过算在被测平台上。

## 活动洞察

侧栏「活动洞察」显示近24小时/7天的调用、成功、失败、接力、已返回Token、输入组成估算、请求时间轴、领取与接力事件。按来源、模型和文字筛选，展开查看供给尝试、原因码、工具名、上下文携带的文件操作分类。

只保存数量、字符长度、白名单工具名及路由元数据，不保存提示词、工具参数、文件路径和结果正文。字符/4是输入体积估算，不是官方计费Token。旧日志没有的上下文数据明确未知；网关看不到客户端绕过它的调用，也不声称观察到DSH内部压缩或实际文件执行完成。

## 管理接口

- `GET /admin/model-relay`：策略、同款候选、冷却原因及当前偏好。
- `POST /admin/model-relay`：`{enabled:true,reservePercent:10,reserveCredits:100,partitions:{workbuddy:true,other:true}}`，短配置提交队列保护并发；全局、分区与单路由开关分别生效。
- 单条路由可设 `relay:false` 保留原行为。全局未启用时原有路由顺序不变。
- `GET /admin/activity-context?range=7d&limit=100&source=dsh`：元数据洞察，最多扫描10000条调用、返回200项；覆盖不足明确标记。
- `GET /admin/free-providers`：带检查日期与出处的免费平台注册表。注册不等于当前免费资格或已调用验证。
- `POST /admin/free-provider-add`：`{providerId:"groq",id:"groq-main",credentialFile:"C:/LOCAL/credential.json",models:[]}`。仅本机凭据文件引用。没有凭据或容量未核验时保存为停用待配置，不伪造连接成功。

接口使用adminKey；推理只使用apiKey。API客户端可用 `X-AI-Credit-Source: hermes` 或 `dsh` 标识来源；其他值归为api，不提供凭据。
