# WB 真实功能自动执行器

## 开启与运行

在「wb帐号池」打开「自动任务」。后端按启用、未封禁账号逐个运行，不切换前台 WorkBuddy 登录。点击现有「一键运行可自动任务」也使用同一执行链。后台调度与每日签到调度独立；关闭自动任务或关闭服务会中止仍在运行的本轮操作。

流程：读取官方任务 → 优先处理首次对话前置任务 → 按每个任务的接受结果确认 → 运行真实功能 → 消费完整进程/工具结果 → 回查官方进度 → 达标领取 → 再查 claimed。HTTP 200、执行器已注册、提交了请求，都不等于完成或已到账。

## 执行组件

使用本机正式 WorkBuddy 随附的 `resources/app.asar.unpacked/cli/bin/codebuddy` 与其静态 product.json，不修改官方文件。优先选用 WorkBuddy 管理的 Node；缺失时使用当前 Node。可通过 `AI_CREDIT_WB_EXECUTOR_CLI` 与 `AI_CREDIT_WB_EXECUTOR_NODE` 显式指定组件路径。

正式 sidecar 宿主契约包含 `CODEBUDDY_HOST=workbuddy-desktop`；执行器沿用该值，让已完成的真实 Skill/专家调用走官方原生结果归属链，不自行构造完成事件。

每个账号有独立的 HOME、配置、工作目录、会话与产物。访问凭据只进入该子进程环境，不进入命令行或共享登录文件。可用工具限定为该任务需要的工具；不继承其他模型供应商的凭据、插件设置、NODE_OPTIONS 或 NODE_PATH。专家仅加载官方角色与插件声明，不执行下载包中的 hooks、脚本或 MCP 设置。

## 功能与结果

- 首次对话、日常对话、指定模型/时间窗口聊天：真实模型回答，要求 exit 0、结构化 success、非空最终结果与完整工具闭环。
- 技能：原样复制本机已安装的真实市场 MarkItDown 技能及原始市场 metadata，真正调用 Skill、使用 Microsoft MarkItDown 转换 HTML 样本，再调用 Read 与宿主独立读回 Markdown。私有 Python 环境位于数据目录 `wb-executor-tools/python`，可用 `AI_CREDIT_WB_EXECUTOR_PYTHON` 指定；缺少依赖会明确等待，不隐式安装。
- 画布：通过官方 Ardot 连接与交换令牌创建新画布，调用设计工具并读取产物；缺少连接时显示待就绪。
- 模板：查询正式 scenes-v2.json，保留真实 scene://ID 和完整官方模板正文，通过官方 ACP 执行，仅选择本地可执行、无额外插件依赖的模板，并核对同一文件 Write/Read/落盘闭环。
- 专家/专家团：获取真实官方目录和角色包，以真实角色启动执行，ACP 同时保留原生 mode/expertId 归属；专家团需要真实成员工具调用。
- 外观：查询官方免费主题，设置后严格读回确认，不凭 POST 返回值判断。
- 资料库：读取实际文档正文，不把空间列表或文档标题当正文读取；没有可读正文则等待。
- 自动化：使用官方本地任务服务创建、读取并暂停本次自动化，防止以后意外重复运行。
- 应用与外部订阅：必须具备真实应用身份、授权及对应运行入口；关注订阅的官方 24 小时条件不被替代为即时完成。

任务界面以官方 current / target 与 claimed 为最终状态。执行器返回 completed 仅说明实际动作已验证，官方尚未记账时仍显示等待回查，不强领未达标奖励。任务依赖、外部授权、不可读正文、夜间窗口和执行组件问题均逐任务保留具体原因，不阻断其他独立任务。

## 防重复与消耗控制

真实生成前查询该账号余额；零余额和余额未确认时不继续付费生成。每个账号、真实登录主体、任务及每日周期有独立持久执行计划。每个动作发送前写 submitted；已完成动作不重复，已发出但结果未知的模型动作只等待核验，不盲目重发。每日任务按 Asia/Shanghai 日期划分。单次执行有超时、输出上限、取消和关闭等待。

本机执行证据位于数据目录 `wb-executor-runtime/<opaque-hash>/last-execution.json`，仅保存退出状态、工具名称、产物标识和统计，不保存原始模型转录或凭据。回执中 execution.completedActions / totalActions 是实际动作进度，不能代替官方积分任务进度。

## 接口与复用

管理 API 保持原有 `/admin/workbuddy/tasks` 查询与运行接口；创建服务时自动注册执行器。测试可通过 `createService(configFile, { workbuddyRuntime })` 注入执行组件、fetch 与轮询间隔，实现无账号、无网络的回归测试。

继续开发时可复用提示：

```text
修改指定 WB 功能执行器，使用本机正式组件或官方业务接口完成真实动作。先保存基线，禁止伪造任务完成遥测。完整消费结果并独立读回产物，随后回查官方 current/target/claimed。对发送结果未知的动作保持幂等，不盲目重放。测试成功、失败、取消、前置条件、关闭与独立回滚，凭据不得进入测试/日志/提交。
```
