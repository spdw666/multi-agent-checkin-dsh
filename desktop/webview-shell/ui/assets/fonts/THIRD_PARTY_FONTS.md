# Bundled interface fonts

Only Montserrat-Regular.otf and Montserrat-Bold.otf are bundled here.
Internal family name was verified as Montserrat using the Windows font API.
Files were reused from the inspected ToolKnit reference snapshot, without edits.
Project: https://github.com/JulietaUla/Montserrat
OFL text: https://raw.githubusercontent.com/google/fonts/main/ofl/montserrat/OFL.txt
The adjacent OFL-1.1.txt is the Montserrat project notice and SIL OFL 1.1 text.
